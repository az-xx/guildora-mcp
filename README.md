# Guildora

Lightweight, pack-based MCP server for Discord, written in TypeScript.

> **Status: early development.** Nothing is published yet. See
> [docs/reference-analysis.md](docs/reference-analysis.md) for the design groundwork.

Guildora is an independent open-source project. It is not affiliated with or endorsed by
Discord Inc. Feature set inspired by [SaseQ/discord-mcp](https://github.com/SaseQ/discord-mcp) (MIT).
